# Boise Glenwood IBM Real-Data Case

This example builds a runnable OpenLimno IBM case for the Boise River at
Glenwood Bridge near Boise, Idaho.

It uses public source data where OpenLimno can use it directly:

- USGS NWIS station `13206000`, daily mean discharge (`00060`, statistic
  `00003`) for 2025-10-01 through 2025-10-14.
- USGS National Hydrography Dataset (NHD) river area permanent identifier
  `120008049`, plus linked Boise River flowlines in the local Glenwood Bridge
  envelope.

The NHD geometry is real GIS data and is written as GeoJSON for Studio import:

- `data/gis/boise_river_nhd_area_120008049.geojson`
- `data/gis/boise_river_nhd_flowline_120008049.geojson`
- `data/gis/habitat_cells.geojson`

The IBM forcing table is `data/hydraulics/hydraulic_cells.csv`. It contains
one row per hydraulic cell per day and includes discharge, water surface,
depth, velocity, cell area, and hydraulic metadata generated by OpenLimno's
`builtin-1d` solver from the NHD boundary/centerline. If a local DEM or
bathymetric transect survey is available, rebuild with the GIS hydraulics
command and pass `--dem`; otherwise OpenLimno uses boundary-width synthetic
cross-sections that should be calibrated before management use.

## Build

```bash
pixi run python examples/boise_glenwood_ibm/build_case.py
```

Use `--offline` after the first build to regenerate derived files from the
saved raw downloads.

## Validate And Run

```bash
pixi run openlimno ibm profile validate examples/boise_glenwood_ibm/profile_rainbow_trout.yaml
pixi run openlimno ibm scenario validate examples/boise_glenwood_ibm/scenario.yaml
pixi run openlimno ibm run examples/boise_glenwood_ibm/scenario.yaml
```

Outputs are written to `examples/boise_glenwood_ibm/out/native/`.

## Rebuild Hydraulics Only

```bash
pixi run openlimno preprocess gis-hydraulics \
  --boundary examples/boise_glenwood_ibm/data/gis/boise_river_nhd_area_120008049.geojson \
  --centerline examples/boise_glenwood_ibm/data/gis/boise_river_nhd_flowline_120008049.geojson \
  --discharge-csv examples/boise_glenwood_ibm/data/flow_daily.csv \
  --out-dir examples/boise_glenwood_ibm/data/hydraulics \
  --cells 12 \
  --slope 0.001 \
  --manning-n 0.035
```

The generated calibration template is
`data/hydraulics/calibration_observed_template.csv`.

## Studio GIS Import

In IBM Studio, use the GIS import panel with:

- Boundary: `examples/boise_glenwood_ibm/data/gis/boise_river_nhd_area_120008049.geojson`
- Centerline: `examples/boise_glenwood_ibm/data/gis/boise_river_nhd_flowline_120008049.geojson`
- Cells: `examples/boise_glenwood_ibm/data/gis/habitat_cells.geojson`
- Hydraulic cells:
  `examples/boise_glenwood_ibm/data/hydraulics/hydraulic_cells.geojson`

This should show the actual NHD river boundary rather than a synthetic channel
shape.
