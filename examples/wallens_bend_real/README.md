# Wallens Bend real HEC-RAS + IBM case

This example builds a runnable OpenLimno hydraulic and IBM case from the USGS
ScienceBase release:

- Title: One-dimensional hydraulic and environmental DNA transport models for
  the Wallens Bend reach of the Clinch River, near Kyles Ford, Tennessee
- DOI: 10.5066/P9D7NCH1
- Collection: https://www.sciencebase.gov/catalog/item/6323764ed34e71c6d67acb60
- HEC-RAS model files: https://www.sciencebase.gov/catalog/item/63238571d34e71c6d67acbdf
- Field WSE/velocity data: https://www.sciencebase.gov/catalog/item/63237e7ad34e71c6d67acbaf

## Build

```bash
pixi run python examples/wallens_bend_real/build_case.py
```

After the raw files have been downloaded once, the case can be rebuilt without
network access:

```bash
pixi run python examples/wallens_bend_real/build_case.py --offline
```

By default the SCHISM workspace is prepared in dry-run mode because SCHISM is
not bundled with OpenLimno. To invoke a configured SCHISM binary/container and
read its NetCDF outputs back into OpenLimno:

```bash
pixi run python examples/wallens_bend_real/build_case.py --offline --run-schism
```

To run through the local SCHISM container built from `containers/schism`:

```bash
docker build -t openlimno-schism:5.11.0 containers/schism
pixi run python examples/wallens_bend_real/build_case.py --offline --run-schism \
  --schism-container-image openlimno-schism:5.11.0 \
  --schism-n-procs 5 \
  --schism-n-scribes 4
```

- `data/cross_sections_all.parquet`: imported HEC-RAS geometry.
- `data/cross_sections_clinch.parquet`: Clinch River main-channel sections.
- `data/hecras_flows.csv`: parsed HEC-RAS flow profiles.
- `data/hydraulic_calibration_grid.csv`: slope/Manning-n grid-search scores.
- `data/hydraulic_calibration_best.json`: selected hydraulic parameters.
- `data/hydraulic_cells.csv`: OpenLimno hydraulic cells with depth, velocity,
  area, WSE, and habitat suitability.
- `data/calibration_summary.csv`: nearest-station comparison against field
  observations for 2021-09-08.
- `data/wallens_bend_hecras_mesh_ugrid.nc`: UGRID-2D mesh derived from HEC-RAS
  `XS GIS Cut Line` coordinates and cross-section elevations.
- `data/schism_handoff/`: SCHISM input/run workspace generated from the
  UGRID mesh (`hgrid.gr3`, `param.nml`, `vgrid.in`, `bctides.in`) plus
  `open_boundary_forcing.csv`, `elev.th`, `flux.th`, and
  `open_boundary_flags.csv`.
- `data/schism_handoff/hydraulic_cells_schism.csv`: generated only after a
  real SCHISM run writes `outputs/out2d_*.nc` or `schout_*.nc`; contains
  OpenLimno-normalized per-node depth, velocity, area, and time fields for IBM
  or habitat post-processing.
- `scenario.yaml`: runnable native IBM scenario.
- `out/native/`: native IBM outputs.

## Notes

The geometry and flow profiles are real HEC-RAS inputs from USGS. The hydraulic
forcing is generated by OpenLimno's builtin normal-depth 1D solver and calibrated
against published 2021-09-08 field WSE/velocity observations. The UGRID/SCHISM
handoff uses real HEC-RAS GIS cutline coordinates and writes upstream/downstream
open boundary segments plus bank land-boundary segments into `hgrid.gr3`.
`open_boundary_forcing.csv` maps HEC-RAS discharge profiles and calibrated
builtin-1d stage/depth/velocity to those open-boundary IDs. Its `time_seconds`
column follows the OpenLimno scenario index, one HEC-RAS profile per simulated
day, while `date` preserves the source profile label. The exported `bctides.in`
now uses SCHISM Type-1 time-history flags: downstream stage boundaries read
`elev.th`, and upstream inflow boundaries read `flux.th` with SCHISM's negative
inflow sign convention. HEC-RAS bed and water-surface elevations are absolute
source-datum values; the SCHISM handoff converts them to one internal datum
before writing `hgrid.gr3` and `elev.th`. A real SCHISM production simulation
still needs modeler review of timestep, tidal options, tracer/temperature/salinity
boundary needs, and any site-specific forcing beyond this steady-profile
handoff. If real SCHISM outputs are present, the builder normalizes node-centred
water depth, velocity components/magnitude, and tributary area into
`hydraulic_cells_schism.csv`. The normal-depth equation also has slope/Manning-n
equifinality, so the full grid should be inspected before management use.
